# Security Policy

## Supported Versions

Since this is an actively maintained academic and personal project, only the latest major release and the `main` branch are officially supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

I take the security of this project seriously. If you discover any security vulnerability, please do not create a public GitHub issue. 

Please report it privately to ensure the safety of the project before a patch is released. You can contact me directly via email:

* **Email:** orcunkundakci@gmail.com 

**What to expect:**
* I will acknowledge the receipt of your vulnerability report within 48 hours.
* If the vulnerability is accepted, I will provide an estimated timeline for the fix.
* Once the issue is resolved, you will be notified, and if you wish, credited for the discovery in the release notes.

Thank you for helping to keep this project secure!
